# modern-training-solutions/moodle-report_customsql fork

Hello! This is the fork of moodle-report_customsql maintained by Modern Training Solutions.

We intend this fork to be temporary until our PRs are accepted upstream. But we are building in the open.

## Branches

- `README` - It only has this note.
- Pull requests - These are based on upstream/main (rebased after any change upstream)
- `production` - The code we run in production. It is built exactly like this:
  - Start with upstream/main
  - Merge PR ...
  - Merge PR ...

## References
